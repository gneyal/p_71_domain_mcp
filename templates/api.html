API Documentation

Generate creative domain and brand name suggestions programmatically.

Endpoint

POST /api/v1/generate

Request Body

{
  "description": "Short, catchy name for a fintech startup",
  "count": 10,
  "tlds": ".com,.io,.ai",
  "check_availability": true
}
description required string

Describe what kind of names you're looking for. Be specific for better results.

count integer, default: 10

Number of suggestions to return. Min: 1, Max: 50.

tlds string, default: ".com,.io,.ai"

Comma-separated list of TLDs to use (e.g., ".com,.io,.co,.ai").

check_availability boolean, default: true

Whether to check domain availability via WHOIS. Set to false for faster results when you just need name ideas.

Response

{
  "suggestions": [
    {
      "name": "finova",
      "domain": "finova.io",
      "reason": "Combines finance and innovation, sounds trustworthy",
      "available": true,
      "price": 32.98,
      "links": {
        "namecheap": "https://namecheap.com/...",
        "godaddy": "https://godaddy.com/...",
        "porkbun": "https://porkbun.com/..."
      }
    }
  ],
  "usage": {
    "input_tokens": 244,
    "output_tokens": 322,
    "total_tokens": 566,
    "cost_usd": 0.0056
  }
}

Response Fields

  • name - The name without TLD
  • domain - Full domain with TLD
  • reason - Why this name fits your description
  • available - true, false, or null (if check_availability is false)
  • price - Estimated yearly price in USD
  • links - Direct links to purchase the domain
  • usage - Token usage and cost for transparency

Examples

cURL

curl -X POST https://your-domain.com/api/v1/generate \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Modern SaaS product for team collaboration",
    "count": 5,
    "tlds": ".com,.io",
    "check_availability": false
  }'

Python

import requests

response = requests.post(
    "https://your-domain.com/api/v1/generate",
    json={
        "description": "AI-powered writing assistant",
        "count": 10,
        "check_availability": False
    }
)

names = response.json()["suggestions"]
for name in names:
    print(f"{name['name']} - {name['reason']}")

JavaScript

const response = await fetch("/api/v1/generate", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    description: "Mobile app for fitness tracking",
    count: 5
  })
});

const { suggestions } = await response.json();
suggestions.forEach(s => console.log(s.name, s.reason));
